> 상태: **착수 가능**. 선행조건 없음. `terminal-gaps-plan.md`·`lazy-route-plan.md` 와 병행 가능.

## 0. 한 줄

**조건이 갈래를 *결정*하지 않고 *편향*하게 만든다.**
실측상 진화 계보 다양성 회복분 전부를 이 한 조각이 담당한다 (아구몬 8가지 → 543가지).

## 1. 증상 — 조건 게이트가 다양성을 죽이고 있다

`docs/global-graph-plan.md` §0 의 목표는 "모든 진화 분기가 그 순간의 조건으로 결정"이다.
그런데 실제로는 조건이 걸린 소수의 노드에서 **후보가 1개로 붕괴**한다.

ctx 를 실사용 패턴으로 고정(세션 8, 턴당 9k)하고 365일 시뮬레이션:

| 팩 | 그래프상 가능 계보 | 365일 노출 | 노출률 |
|---|---|---|---|
| agumon | 498 | **8** | 1.6% |
| keramon | 91 | 79 | 87% |

아구몬 8가지를 열면 원인이 보인다 — **365일 내내 앞 3칸이 동일하다.**

```
56일  아구몬 → 지오그레이몬 → 라이즈그레이몬 → 마왕몬
55일  아구몬 → 지오그레이몬 → 라이즈그레이몬 → 멧돼지몬
      … 8개 전부 앞 3칸이 같다. 변하는 건 궁극체 칸뿐
```

`아구몬` 의 자식 28개 = `지오그레이몬{sessionCount≥5}` 1 + 케어미스 3 + **무조건 24**.
매일 세션을 5개 이상 켜므로 게이트가 매일 발동하고, 나머지 27개가 매일 전멸한다.
`지오그레이몬` 에도 같은 게이트가 또 있어 `라이즈그레이몬` 도 확정.

**조건이 하나도 없는 keramon 이 가장 다양하다(87%).** 설계 의도의 정반대다.

## 2. 원인 — `candidatesFor()` 의 동률필터

`lib/daily.js:433` 부근:

```js
const met = links.filter((e) => conditionMet(e.when, ctx));
const pool = met.length > 0 ? met : links;
const winner = JSON.stringify(pool[0].when);
const tied = pool.filter((e) => JSON.stringify(e.when) === winner);
return tied.map(e => e.node);
```

`readGraph`(`lib/daily.js:154`) 가 `childrenOf` 를 **조건부 먼저 / 무조건 나중**으로
정렬한다. 따라서 조건부 엣지가 하나라도 발동하면 `pool[0].when` 이 그 조건이 되고,
`tied` 가 **JSON 이 완전히 같은 엣지만** 남긴다 → 무조건 형제 전원 탈락.

즉 조건은 가중치가 아니라 **우선순위 스위치**다. 이것이 24 → 1 붕괴의 기계적 원인.

## 4. 변경

### 반환 계약

```
candidatesFor(node, ctx, childrenOf)
  before:  [node, node, ...]
  after:   [{ node, weight }, ...]
```

- 조건 통과 엣지 → `weight = W`
- 무조건 엣지 → `weight = 1`
- 조건 불통과 엣지 → 제외 (`weight = 0`)
- 전부 제외되면 무조건 엣지 전체를 `weight = 1` 로 폴백 (도달 보장 계약 유지)

`pick()` 은 `hash % length` 에서 **가중 추첨**으로 바뀐다.

### `W` 값

실측(20,000 시행):

| W | 아구몬 계보 수 | 완전체 종점률 |
|---|---|---|
| ∞ (현행) | 8 | 11.2% |
| 16 | 543 | 10.1% |
| 8 | 543 | 9.6% |

`W=8` 과 `W=16` 의 계보 수는 같다. 차이는 종점률 0.5%p 뿐이다.
**`W=∞` 가 현행 동작이므로 연속적으로 후퇴 가능하다** — 문제가 생기면 값만 올리면 된다.

### 호출부

`selectRoute` 의 forward walk 와 prefix(backward) walk 양쪽. 종점 판정
(`candidatesFor(...).length === 0`) 은 그대로 동작한다.
