## 권장 순서 (강제 아님)

**terminal-gaps → gate-weighting → lazy-route**

- terminal-gaps 는 데이터 수정이라 리스크가 낮고 체감이 즉시다. 골든 테스트도 안 건드린다
- gate-weighting 은 사용자 불만("루트가 고정된다")에 직접 대응하고 효과가 가장 크다.
  단 **골든 픽스처를 의도적으로 갱신해야 하는 유일한 계획**이라 그 전에 그래프가 정상인
  편이 검수하기 낫다
- lazy-route 는 다양성 기여가 0 이므로 앞의 둘 뒤에 두고, 필요성을 다시 판단해도 된다
